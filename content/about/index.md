# About HyHOPE

HyHOPE is a planned cross-border Hydrogen Valley across Austria, Hungary and Slovakia, designed as one integrated ecosystem. The project intends to deploy 60 MW of electrolysis capacity using a decentralised country approach with shared distribution infrastructure. Production, trailer-based distribution, refuelling, industrial and mobility offtake, seasonal and underground storage and gas-grid injection are to be combined in a single operational framework.
